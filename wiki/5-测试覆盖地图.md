## 一键运行所有测试

```bash
cd /Users/allen/.openclaw/workspace/.deepflow

import subprocess, sys, os

tests = [
    ('tests/test_path_config.py', 'Core: PathConfig'),

    ('tests/test_e2e_living_spec_v2.py', 'Spec Pro: Living Spec 2.0.0 E2E'),

    ('domains/ship_pro/eval/test_eval_checks.py', 'Ship Pro: L2 代码检查'),
    ('domains/ship_pro/eval/test_gates.py', 'Ship Pro: 质量门控'),
]

passed = 0
for path, desc in tests:
    r = subprocess.run([sys.executable, path], capture_output=True, text=True, timeout=60,
                      env={**os.environ, 'PYTHONPATH': '.'})
    ok = r.returncode == 0
    if ok: passed += 1
    status = '✅' if ok else '❌'
    print(f'{status} {desc}')

print(f'\n总计: {passed}/{len(tests)} 通过')
"
```

## 如何添加新测试

1. 在 `tests/` 或 `domains/{domain}/eval/` 创建 `test_*.py`
2. 使用标准测试框架 (pytest 或自定义):
   ```python
   def test_example():
       # 准备
       spec = {...}
       
       # 执行
       result = merge_spec(spec)
       
       # 断言
       assert result["status"] == "success"
   ```
3. 添加到本文件的对应域
4. 运行验证:
   ```bash
   PYTHONPATH=. python3 tests/test_example.py
   ```
