## 恢复概览

当 `.deepflow/` 目录数据丢失时，按以下优先级恢复：

1. **Git 仓库** - 代码文件 (最快)
2. **Session 日志** - Blackboard 数据 (最完整)
3. **MEMORY.md** - 架构决策和配置 (辅助)

## 2. Blackboard 数据恢复

### 2.1 使用恢复脚本

**脚本**: `scripts/blackboard_recover_all.py`

```bash
cd /Users/allen/.openclaw/workspace/.deepflow
python3 scripts/blackboard_recover_all.py
```

**工作原理**:
1. 扫描所有 session 日志 (`~/.openclaw/agents/*/sessions/*.jsonl`)
2. 提取 `toolCall` 类型的 `write` 操作
3. 过滤 `blackboard/` 路径
4. 按时间排序（后写的覆盖先写的）
5. 写入对应路径

**输出示例**:

### 2.2 手动恢复特定会话

如果需要恢复特定会话的数据：

```python
import json
from pathlib import Path

SESSION_FILE = Path("~/.openclaw/agents/main2/sessions/{session_id}.jsonl").expanduser()
BLACKBOARD = Path("/Users/allen/.openclaw/workspace/.deepflow/blackboard")

def extract_writes(session_file):
    writes = {}
    with open(session_file, 'r') as f:
        for line in f:
            obj = json.loads(line.strip())
            msg = obj.get('message', {})
            content = msg.get('content', [])
            
            if not isinstance(content, list):
                continue
            
            for block in content:
                if (isinstance(block, dict) and 
                    block.get('type') == 'toolCall' and 
                    block.get('name') == 'write'):
                    
                    args = block.get('arguments', {})
                    path = args.get('path', '')
                    content_text = args.get('content', '')
                    
                    if 'blackboard/' in path and content_text:
                        # 提取 blackboard/ 后的路径
                        rel_path = path.split('blackboard/')[-1]
                        writes[rel_path] = content_text
    
    return writes

# 使用
writes = extract_writes(SESSION_FILE)
for rel_path, content in writes.items():
    target = BLACKBOARD / rel_path
    target.parent.mkdir(parents=True, exist_ok=True)
    target.write_text(content)
    print(f"✅ {rel_path}")
```

## 5. 常见问题

### Q1: Session 日志太大，扫描很慢？

**A**: 使用过滤条件：
```python
# 只扫描最近 7 天的 session
import time
cutoff = time.time() - 7 * 86400

for session_file in SESSIONS_DIR.glob("*.jsonl"):
    if session_file.stat().st_mtime > cutoff:
        # 处理
```

### Q2: 恢复的文件格式不对（JSON 解析失败）？

**A**: Session 日志中的内容可能有转义：
```python
import json

# 尝试多次解析
content = raw_content
try:
    data = json.loads(content)
except json.JSONDecodeError:
    # 尝试去除转义
    content = content.replace('\\"', '"').replace('\\n', '\n')
    data = json.loads(content)
```

### Q3: 某些 Blackboard 目录恢复不完整？

**A**: 可能原因：
1. Session 日志被清理
2. 文件是在其他 session 中写入的
3. 文件路径不在 `blackboard/` 下

**解决**:
```bash
# 搜索所有包含该路径的 session
grep -r "blackboard/spec_spec_123456" ~/.openclaw/agents/*/sessions/*.jsonl
```

### Q4: 恢复后测试失败？

**A**: 按以下步骤排查：
1. 检查 Python 导入路径: `PYTHONPATH=.`
2. 检查依赖是否安装: `pip list | grep pytest`
3. 查看具体错误: `python3 tests/test_*.py 2>&1 | tail -20`
4. 对照 Wiki 检查函数签名是否匹配

## 6. 预防措施

```bash

    /Users/allen/.openclaw/workspace/.deepflow/blackboard/

# 保留最近 7 天
find ~/backups -name "blackboard_*.tar.gz" -mtime +7 -delete
```
