# 恢复手册

> 数据丢失后的完整恢复指南  
> 最后更新: 2026-07-08

---

## 恢复概览

当 `.deepflow/` 目录数据丢失时，按以下优先级恢复：

1. **Git 仓库** — 代码文件 (最快)
2. **Session 日志** — Blackboard 数据 (最完整)
3. **MEMORY.md** — 架构决策和配置 (辅助)

---

## 1. 代码文件恢复

### 1.1 从 Git 恢复

```bash
cd /Users/allen/.openclaw/workspace/.deepflow
git checkout HEAD -- .
```

### 1.2 检查差异

```bash
git status
git diff HEAD
```

### 1.3 应用未提交的改动

如果有未提交的改动（如恢复后的新功能），手动重新应用。

---

## 2. Blackboard 数据恢复

### 2.1 使用恢复脚本

**脚本**: `scripts/blackboard_recover_all.py`

```bash
cd /Users/allen/.openclaw/workspace/.deepflow
python3 scripts/blackboard_recover_all.py
```

**工作原理**:
1. 扫描所有 session 日志 (`~/.openclaw/agents/*/sessions/*.jsonl`)
2. 提取 `toolCall` 类型的 `write` 操作
3. 过滤 `blackboard/` 路径
4. 按时间排序（后写的覆盖先写的）
5. 写入对应路径

### 2.2 手动恢复单个会话

```bash
# 查找特定会话的 blackboard 写入
cat ~/.openclaw/agents/*/sessions/*.jsonl \
  | jq -r 'select(.type=="toolCall" and .toolName=="write" and (.input.path | contains("blackboard"))) | .input.path' \
  | sort -u
```
