⑥ Blackboard 协议 Agent 通信机制

所有 Agent 间的唯一状态共享机制 — JSON 文件读写协议
📋 blackboard/{session_id}/
spec/ · 规格文件
input.md living_spec.json quality_report.json harness_report.json round_result.json coord_state.json
spec/ · 追踪文件
quality_trajectory.json conversation_log.json execution_log.json user_response_round_N.md
stages/ · 中间产物
round_NN_parse.json round_NN_questions.json round_NN_response.json consolidator.json fix.json
读写规则
📝 Writer（写者）
ParseWorker 首次创建 living_spec.json
Orchestrator Worker 合并增量到 confirmed 层
每轮追加 trajectory + conversation log
👁️ Reader（读者）
QuestionWorker / AssessWorker 读取 living_spec
HarnessWorker 读取全部报告
下游引擎（Solution Pro）读取输出
核心原则
📄 文件是唯一的 Agent 间通信机制
🔒 不通过函数参数传递状态
✅ 写者协议：追加新项，不删除已有项
⚠️ 矛盾时保留两者并标注 contradiction
