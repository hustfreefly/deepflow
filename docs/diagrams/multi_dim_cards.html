VIEW 04 · 质量保障维度
四层质量门禁
每个环节都有质量检查，不靠自觉靠机制
LAYER 1 · 输入门禁
🛡️ Input Guard
检查回答是否为空、有意义、不矛盾、跟问题相关
触发时机：每轮收到用户回答时
LAYER 2 · 过程门禁
⚙️ Process Guard
监控进度速率、推断完整性、对话均衡性，发现异常自动调整
触发时机：每轮评分后
LAYER 3 · 输出门禁
🔒 Harness
5 维加权评分：清晰度/完整度/可执行度/一致度/适配度
触发时机：质量达标后 · 最终产出前
LAYER 4 · 安全阀
🚨 Safety Valve
max_rounds 限制 · 质量回退检测 · 无效输入连击 · Worker 连续超时
触发时机：全程监控
Harness 决策
PASS → 通过| WARN → 标注风险| SOFT_BLOCK → 用户可 override| HARD_BLOCK → 继续收集
契约 Cage
6 个活跃契约：spec_pro_v2.0 · solution_v1.0 · investment_v2.0
research_pro_v1.0 · root_cleanup · version_mgmt
契约 = 行为"宪法"，每次修改前必须读
